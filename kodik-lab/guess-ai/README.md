# Игра «Фото или нейросеть?» — урок 20

Готовая HTML-игра на 8 раундов для детей 1–4 классов.

## Запуск
Откройте `index.html` в браузере. Для загрузки фотографий и ИИ-картинок нужен интернет.

Для постоянной веб-ссылки можно включить GitHub Pages в репозитории `MaretDangaeva/presentation`: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**. Когда публикация заработает, путь к игре будет: `https://maretdangaeva.github.io/presentation/kodik-lab/guess-ai/`.

## Правила
Выберите созданную ИИ картинку из двух изображений. Ответьте мышкой или клавишами **1** / **2**. После выбора появятся правильные ответы, информация о генераторе, авторе фотографии и ссылки на оригиналы на Wikimedia Commons. После 8 раундов — итоговый счёт и возможность сыграть снова.

Игра не требует регистрации и не собирает персональные данные учеников. Изображения подгружаются из Wikimedia Commons. Права на отдельные фотографии и указание авторов приведены на страницах источников.

## Для преподавателя
Игра рассчитана примерно на 4–5 минут — пока Leonardo генерирует второй 5-секундный ролик. Вопрос для обсуждения после игры: «Почему внешнего вида картинки недостаточно, чтобы наверняка определить её происхождение?»
